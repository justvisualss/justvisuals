# justvisuals

A polished visual design playground for generating creative color palettes, gradients, and modern UI mockups.

## What it does

justvisuals is a lightweight web app that helps designers and developers explore visual ideas quickly. It creates curated palettes, previews typography and UI surfaces, and makes color workflows easier to iterate on.

## Features

- Generate balanced brand-inspired color palettes
- Preview gradients and UI mockups instantly
- Copy individual colors or the full palette to the clipboard
- Responsive layout for desktop and mobile
- Clean dark-mode design system aesthetic

## Run locally

Because this project is static, you can open `index.html` directly in a browser or serve it locally:

```bash
cd justvisuals
python3 -m http.server 8000
```

Then visit:

http://localhost:8000

## Why this project matters

Modern product design and front-end work depend on fast visual iteration. justvisuals turns that process into a simple, accessible workflow for building usable, attractive palettes and mockups without requiring complex tooling or subscriptions.
